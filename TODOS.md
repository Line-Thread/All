### Blog CMS migration
**What:** Migrate blog from static HTML to a lightweight CMS (Keystatic, Decap, or a Markdown-to-HTML build script).
**Why:** Blog velocity is currently gated by the need to write raw HTML per article. At 15-20+ articles this becomes a real publishing bottleneck.

**Context:** Currently 9 articles live, all static HTML. Claude Code can generate HTML quickly enough that this isn't urgent yet. Revisit when publishing pace drops below one article per 2 weeks due to friction.
**Effort:** M (human: ~1 day / with CC+gstack: ~2h)
